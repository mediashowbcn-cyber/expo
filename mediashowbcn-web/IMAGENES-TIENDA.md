# Imágenes que hay que subir a la tienda

**Dónde subir:** WordPress → Productos → (abre el producto) → panel derecho **«Imagen del producto»** → Establecer imagen. Después «Actualizar».

**Cómo debe ser cada foto:**
- Formato horizontal o cuadrado, **mínimo 1200 × 1200 px**, JPG.
- Fondo neutro o la sala real; sin texto ni logos de otras marcas.
- Nombre de archivo descriptivo, por ejemplo `alto-trx315-montado.jpg`.
- Foto real del equipo o del montaje. Si es un render, márcalo como «ilustrativo» en la descripción.
