# Media Show BCN — landing page

Página de aterrizaje de [www.mediashowbcn.com](https://www.mediashowbcn.com). Es un único archivo `index.html` sin dependencias: HTML, CSS y JavaScript en línea, con las fuentes Unbounded, Manrope y JetBrains Mono desde Google Fonts.

## Ver en local

Abra `index.html` en el navegador, o sirva la carpeta:

```sh
npx serve mediashowbcn-landing
```

## Publicar

Suba `index.html` a cualquier hosting estático (Netlify, Vercel, GitHub Pages, Cloudflare Pages) y apunte el dominio `www.mediashowbcn.com`.

## Contenido

- Tema moderno propio: azul cobalto `#2B36F5`, amarillo señal `#FFD23F` y neutros grafito, con modo claro y oscuro.
- El formulario de presupuesto prepara un mensaje de WhatsApp para el 615 78 20 87. No envía datos a ningún servidor.
